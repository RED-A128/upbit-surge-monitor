# Upbit Surge Monitor — Clean V001

## 프로젝트 소개

**Upbit Surge Monitor**는 업비트 KRW 마켓 전체 종목을 대상으로

> 향후 **30% 이상 급등할 가능성이 있는 코인을 급등 전에 탐지**

하는 것을 목표로 하는 데이터 분석 및 패턴 연구 프로젝트입니다.

이 프로젝트의 핵심은 이미 급등한 코인을 찾는 것이 아니라,

**급등이 시작되기 전에 의미 있는 징후를 찾아내는 것**입니다.

---

## 프로젝트 목표

최종적인 시스템 흐름은 다음과 같습니다.

```text
업비트 KRW 전체 시장 데이터 수집
        ↓
원본 OHLCV 장기간 축적
        ↓
급등 전 패턴 연구
        ↓
패턴 조건 수치화
        ↓
과거 데이터 백테스트
        ↓
30% 이상 급등 여부 검증
        ↓
실시간 Scanner
        ↓
급등 가능 후보 탐지
        ↓
휴대폰 알림
        ↓
사용자가 직접 차트 확인
        ↓
사용자가 직접 매매 판단
